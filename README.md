# 📌 Job Application Tracker

A lightweight **Job Application Tracker** built with vanilla **HTML, CSS, and JavaScript**.  
It helps you stay organized while applying for jobs by tracking applications, statuses, follow-ups, recruiter details, and more — all in your browser with **no backend required**.

---

## 🚀 Features

- 📊 **Dashboard Stats**
  - Track total applications, pending, interviews, offers, and response rate.

- 🎨 **Dark Mode Support**
  - Toggle between light and dark themes with a simple switch.

- ➕ **Add Applications Easily**
  - Company name, position, dates, method, job URL  
  - Status (Applied, Interview, Offer, Rejected, etc.)  
  - Salary, visa sponsorship, recruiter contact, notes

- 🔍 **Smart Filters & Search**
  - Filter by status (Applied, Interview, Offer, etc.)  
  - Filter by visa sponsorship (Yes / No / Unknown)  
  - Search by company name

- 🗂 **Bulk Actions**
  - Select multiple applications at once  
  - Delete selected rows  
  - Clear selection with one click

- 📤 **Export to CSV**
  - Backup your data or analyze it further in **Excel / Google Sheets**.

- 🗑 **Clear All Data**
  - Reset tracker instantly when starting fresh.

- ✏️ **Edit Applications**
  - Update application details with an inline edit form.

- 📱 **Responsive Design**
  - Fully usable on desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript  
- **Styling:** Custom CSS with light/dark theme variables  
- **Storage:** Browser LocalStorage (no server required)

---

## 📖 How to Use

- After each job application, click “+ Add New Application” to record it.
- Use status dropdowns to keep progress updated.
- Check response rate stats on the dashboard.
- Export your applications as CSV for external use.
- Toggle Dark Mode for a comfortable viewing experience.

---

## 💡 Pro Tips

- Follow up on pending applications after 1–2 weeks.
- Regularly export CSV backups for safekeeping.
- Use color-coded statuses for a quick visual scan:

      ✅ Green → Progressing (Interview, Offer)
  
      ❌ Red → Closed (Rejected, Withdrawn)
